Every component, rebuilt on Material 3 Expressive: tonal colour roles from a seed, the expanded shape scale and morphing shapes, spring motion, state layers and the new expressive components. Pick a seed colour or switch the theme at the top; everything on the page follows.

Foundations

Colour 2.12.2

Every colour is a role, not a hex. Accent roles come in four (colour, on-colour, container, on-container); surfaces step through five container levels. Extended roles give status colours the same structure. Pick a seed in the top bar to regenerate them all.

Typography 2.3

The Material type scale: five roles in three sizes. Brand roles (display, headline, title large) use the brand face; the rest use the plain face. Emphasized styles add weight for the one thing on screen that should lead.

Shape 2.4

Ten corner sizes, from square to full, including the expressive "increased" and extra-extra-large steps. Beyond corners, a library of abstract shapes adds emphasis: avatars, icon containers, empty states and the loading indicator. They share point counts, so any shape can morph into any other.

Elevation 2.5

Six levels. Hierarchy comes first from surface container colour; shadows are added only for things that float (FABs, menus, dialogs, toolbars, snackbars).

Motion 2.6

Spring physics, not durations. Spatial springs move, resize and reshape things and may overshoot; effects springs fade and recolour and never overshoot. Each comes fast, default and slow. CSS runs them as precomputed linear() curves.

Reduced motion collapses every spring to an instant change.

State layers 2.7

Interaction is shown by a translucent layer of the content colour over the container (hover 8%, focus 10%, pressed 10% plus a ripple), and on buttons by a change of shape.
